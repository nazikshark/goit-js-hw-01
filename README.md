# GoIT JavaScript Homework #01

This repository contains the first homework assignment for the JavaScript course. The project focuses on basic syntax, variables, data types, and function declarations.

## 📋 Project Overview
The assignment consists of three tasks aimed at practicing:
- Function declarations with parameters.
- Mathematical operations and string template literals.
- Using `Number.parseFloat()` to handle CSS-like strings.

## 🚀 Tasks Description:

### Task 1: Droid Sales Station (`task-1.js`)
A function `makeTransaction(quantity, pricePerDroid)` that calculates the total cost of an order and returns a message using template literals.

### Task 2: Shipping Cost Calculation (`task-2.js`)
A function `getShippingMessage(country, price, deliveryFee)` that sums the item price and shipping fee, returning a delivery notification.

### Task 3: Element Width Calculation (`task-3.js`)
A function `getElementWidth(content, padding, border)` that:
- Takes strings like `"50px"`.
- Converts them to numbers.
- Calculates total width according to the `border-box` model (Total = content + 2 * padding + 2 * border).

## 🛠 Technologies Used:
- JavaScript (ES6+)
- Prettier (for code formatting)
